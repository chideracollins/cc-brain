# Interview Prep Tracker

This folder contains a lightweight markdown tracking system for interview preparation.
It includes a weekly review that can be synced to GBrain and surfaced in the portfolio.

- `tracker.md` – master index linking to the detailed logs.
- `WeakestTopics.md` – table of topics with current proficiency levels.
- `SolvedLog.md` – chronological log of solved problems.
- `MockInterviews.md` – records of mock interview sessions and applied feedback.

Each file is designed to be edited manually after practice sessions.
